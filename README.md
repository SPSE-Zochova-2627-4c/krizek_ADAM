# krizek_ADAM
Navrhnite a vytvorte webovú aplikáciu pre študentov na organizáciu
školských povinností a voľného času. Má obsahovať dashboard, v ktorom je
kalendár, kde si vie používateľ upraviť udalosti, to-do list zadaní, priemer
známok a dôležité upozornenia ako testy, či domáce úlohy. Používateľ si vie
pridať svoju vlastnú triedu, rozvrh a rozdeliť si zadania podľa predmetov a
pridať ich výsledky. Aplikácia umožní používateľovi registráciu, prihlásenie a
ukladanie údajov do databázy
