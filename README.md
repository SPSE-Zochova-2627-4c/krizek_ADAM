# ADAM

Webová aplikácia pre študentov na organizáciu školských povinností a voľného času.

## Opis projektu

**Čo to je:** webová aplikácia, ktorá študentovi na jednom mieste zhromažďuje všetko, čo potrebuje k školskému životu.

**Čo to robí:**

- **Dashboard** – prehľadná úvodná stránka s kalendárom, to-do listom, priemerom známok a dôležitými upozorneniami.
- **Kalendár** – používateľ si môže udalosti pridávať, upravovať a mazať.
- **To-do list zadaní** – zadania rozdelené podľa predmetov.
- **Známky** – evidencia výsledkov z jednotlivých predmetov a automatický výpočet priemeru.
- **Upozornenia** – pripomienky dôležitých termínov, napríklad testov a domácich úloh.
- **Vlastná trieda a rozvrh** – používateľ si vie vytvoriť triedu, zadať rozvrh a predmety.
- **Účty používateľov** – registrácia, prihlásenie a ukladanie údajov do databázy.

## Technológie

> Technológie sa ešte budú upresňovať, zatiaľ ide o návrh.

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js (Express)
- **Databáza:** SQLite
- **Autentifikácia:** sessions / JWT s hashovaním hesiel (bcrypt)
